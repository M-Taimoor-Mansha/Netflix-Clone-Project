# Netflix Clone Project

A responsive landing page clone of Netflix built using HTML, CSS, and JavaScript.

## Features
- Fully responsive layout for desktop, tablet, and mobile devices
- Interactive FAQ accordion section
- Netflix UI design and styling

## Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript**

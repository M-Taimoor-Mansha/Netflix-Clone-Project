# 🎬 Netflix Clone — Responsive Web Application

A clean, modern, and pixel-perfect clone of the Netflix landing page built from scratch using pure **HTML5**, **CSS3**, and **Vanilla JavaScript**. This project focuses on UI fidelity, mobile responsiveness, and interactive DOM components.

## 🚀 Key Features

- **Hero Landing Page:** Authentic dark theme styling complete with radial gradient overlays and hero email submission form.
- **Interactive FAQ Accordion:** Clean JavaScript-driven toggle functionality for smooth expand/collapse behavior on common questions.
- **Fully Responsive Design:** Optimized layout for seamless viewing across smartphones, tablets, laptops, and desktop displays.
- **Custom UI Components:** Custom-styled input fields, buttons, language selector dropdowns, and section dividers matching the original interface.
- **Cross-Browser Compatible:** Tested and verified across major modern browsers (Chrome, Firefox, Edge, Safari).

---

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3 (Flexbox & Grid Layouts, Custom Properties / CSS Variables)
- **Scripting:** Vanilla JavaScript (ES6+ DOM manipulation & event handlers)
- **Icons & Typography:** SVG Icons / Google Fonts
